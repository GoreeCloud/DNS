# GoreeCloud DNS security

GoreeCloud DNS is in Fork-to-Native development and is **not qualified for production deployment**. Do not expose an unaudited management interface or recursive DNS resolver to the public Internet.

Never disclose vulnerabilities, secrets, personal DNS histories or private network configurations in public GitHub issues. Contact GoreeCloud maintainers through a private security-reporting route if available. The original upstream disclosure guidance is retained under docs/upstream/SECURITY.md, but upstream maintainers are not responsible for GoreeCloud modifications.
