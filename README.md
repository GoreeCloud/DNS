# GoreeCloud DNS

GoreeCloud DNS is a privacy-first, self-hosted DNS platform under active Development.

The product is intended to combine recursive resolution, authoritative DNS, encrypted DNS, network-wide filtering, policy, DHCP integration, observability, automation, and resilient multi-node operation while preserving administrator ownership and GoreeCloud privacy/security boundaries.

> **Current implementation status:** The current `GoreeCloud/DNS` repository is a recreated repository lineage and presently contains documentation only. No DNS runtime implementation, deployment, release artifact, production acceptance, or Stable status is verified in this repository.
